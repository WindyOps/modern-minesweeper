# Modern Minesweeper

![Python](https://img.shields.io/badge/Python-3.9%2B-blue)
![License](https://img.shields.io/badge/License-MIT-green)

A modern Minesweeper game built with Python and Tkinter. Zero third-party dependencies, ready to play out of the box.

## ✨ Features
- 🎮 **Three difficulties**: Easy (9x9/10 mines), Medium (16x16/40 mines), Hard (16x30/99 mines)
- 🛡️ **Safe first click**: Never step on a mine on your first move
- 🌊 **Auto-expand**: Clicking a blank cell automatically opens surrounding areas using BFS
- 🚩 **Right-click to flag**: Mark suspected mines easily
- ⏱️ **Timer & remaining mines**: Track your progress in real-time
