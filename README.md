# Modern Minesweeper
A modern Minesweeper game built with Python and Pygame.

## Features
| Feature | Status |
|----------|----------|
| Classic Gameplay | ✅ |
| Safe First Click | ✅ |
| Multiple Difficulty Levels | ✅ |
| Custom Board Sizes | ✅ |
| Flag System | ✅ |
| Win/Loss Detection | ✅ |
| Clean User Interface | ✅ |

## Installation

cd modern-minesweeper

pip install -r requirements.txt

## Run

python main.py

## Controls

| Key | Action |
|------|------|
| Left Click | Reveal Cell |
| Right Click | Toggle Flag |
| R | Restart Game |
